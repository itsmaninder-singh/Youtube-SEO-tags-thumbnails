A powerful **YouTube SEO Tags & Thumbnail Generator** built using **Java, Spring Boot, and Thymeleaf**. This application helps content creators optimize their YouTube videos by generating SEO-friendly tags and downloading high-quality video thumbnails quickly and efficiently.

## ✨ Features

- 🏷️ Generate SEO-friendly YouTube tags
- 🖼️ Download high-quality YouTube thumbnails
- ⚡ Fast and responsive web interface
- 🎨 Clean UI built with Thymeleaf
- 🔍 Easy YouTube URL processing
- 📱 Responsive design for desktop and mobile

## 🚀 Getting Started

### Prerequisites

- Java 17+
- Maven
- IDE (IntelliJ IDEA / Eclipse / VS Code)

### Installation

```bash
git clone https://github.com/your-username/youtube-tools.git
```

```bash
cd youtube-tools
```

```bash
mvn spring-boot:run
```

Open your browser and visit:

```text
http://localhost:8080
```
